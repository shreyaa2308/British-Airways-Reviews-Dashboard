# British Airways Reviews Dashboard (Tableau)
Interactive Tableau dashboard visualizing British Airways customer reviews, highlighting passenger sentiment, ratings, and key service performance metrics to uncover insights into customer experience.
This project transforms raw customer feedback into visual analytics, making it easier to understand how travelers perceive the airline across different dimensions.

KEY FEATURES:
Overall Ratings Summary - Distribution of passenger ratings (out of 5).
Sentiment Analysis - Positive, Neutral, and Negative review breakdown.
Service Performance - Ratings across categories such as Cabin Staff, Food & Beverages, Entertainment, Seat Comfort, and Value for Money.
Route Insights - Comparison of review scores by route and region.
Traveler Demographics - Ratings segmented by traveler type (Business, Leisure, Solo, Couple).
Interactive Filters - Drill down by year, traveler type, cabin class (Economy, Business, First), or flight route.

INSIGHTS UNCOVERED:
Strengths: Cabin crew friendliness and onboard service score highly.
Weaknesses: Food & Beverages and Entertainment receive lower ratings.
Traveler Types: Business-class passengers report higher satisfaction compared to economy travelers.
Regional Variations: Long-haul flights receive better ratings than some short-haul routes.
Value Perception: Many customers highlight that ticket prices don’t always match the service experience.

PROJECT DETAILS:
Tool Used: Tableau
Dataset: British Airways customer reviews (ratings, comments, routes, traveler profiles)
File Included: British Airways Reviews Dashboard.twb (Tableau workbook)
